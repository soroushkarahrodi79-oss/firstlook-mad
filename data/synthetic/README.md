# data/synthetic

Datasets sintéticos pequeños y reproducibles (seeds fijas) para demos y tests.
Siempre etiquetados nature=SYNTHETIC. Nunca se mezclan con datos reales sin marca.
Phase 0C los genera en memoria desde `configs/phase0c_synthetic.json`; no son
ubicaciones ni incidentes reales de Madrid. El resultado reproducible se conserva
en `outputs/reports/phase0c_synthetic_results.json`.
